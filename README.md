# MyCAD

Korruse- ja ruumiplaanide joonistaja (Python + Tkinter). Autor: Germo, Eesti.

Floor plan maker written in Python + Tkinter, standard library only.

## Käivitamine / Running

    py mycad.pyw

Vaja on Python 3.8+ koos Tkinteriga – pip-pakette pole vaja.
Requires Python 3.8+ with Tkinter; no pip packages needed.

## Exe (Windows)

Topeltklõpsa `build.bat` – valmis fail tekib `dist\MyCAD.exe`.
Double-click `build.bat`; the result is `dist\MyCAD.exe`.
